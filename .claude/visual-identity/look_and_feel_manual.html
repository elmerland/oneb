SEC 001

Color · Palette

· 5 accents + ink + paper

Five bright, screen-lit accents on a paper-cream ground with deep ink for structure. Each accent has a fixed role — used to color the section markers and divider — so the five colors stay legible together rather than competing.

SEC 002

Typography

· one family, four weights

OneB runs on a single typeface — IBM Plex Mono — across the whole template. The monospace grid is part of the brand: it's what makes the logbook feel like a logbook. Headlines lean heavy and uppercase; body sets at a comfortable reading size.

SEC 004

Usage rules

· keep it tight

Do

  • Use ink black for structure, accents for emphasis only — one accent per element.
  • Stick with IBM Plex Mono. Heavy + uppercase for headlines; regular for body.
  • Keep hard 6/4/3px offset shadows pointing the same direction (down-right).
  • Set body inside a 74ch column. Plain date above, no chip, no left rule.
  • Reserve chromatic aberration for hover/active states: logo + nav tiles only.

Don't

  • Don't introduce gradients, soft shadows, or rounded corners.
  • Don't pair accents into 50/50 backgrounds. Accents are ink on cream, never the field.
  • Don't add a second display typeface. The grid is the brand.
  • Don't use emoji or stock iconography — ASCII glyphs only.
  • Don't shift link color on hover — underline reveal is the only signal for body links.
  • Don't recolor dates, body rules, or post titles with the accent set — ink only.
SEC 005

CSS tokens

· paste into :root

Drop-in token block for the full palette. The five accents map to per-post roles (LOG 001 → 005) in order — don't recolor without updating both ends.

:root {
  --bg:       #fafaf5;   /* paper cream */
  --ink:      #171a20;   /* ink black   */
  --plate:    #171a20;
  --cream:    #fafaf5;
  --hair:     rgba(23, 26, 32, 0.16);

  --c-red:    #ff5d3a;   /* amber flare    */
  --c-cyan:   #00c2ff;   /* ice cyan       */
  --c-yellow: #ffd60a;   /* hot yellow     */
  --c-plum:   #ff2d75;   /* magenta pulse  */
  --c-green:  #00d97e;   /* phosphor green */
}
